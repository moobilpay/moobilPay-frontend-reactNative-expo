Déploiement App Store

MoobilPay · Guide complet pour publier sur l'App Store iOS

1 Côté Apple Developer

Compte payant requis : 99 USD/an ✅ déjà fait

  • App ID com.moobilpay.com avec capabilities Sign in with Apple + Push Notifications
  • Clé APNs .p8 uploadée dans Firebase
  • Vérifier le statut du compte : developer.apple.com/account → ton compte doit être Active. Renouvellement annuel sinon tout est suspendu.

2 Créer l'app sur App Store Connect

Va sur appstoreconnect.apple.com → Mes apps → bouton + → Nouvelle app.

Champs à remplir

  • Plateformes : iOS
  • Nom : MoobilPay (30 caractères max, unique mondialement — vérifie qu'il n'est pas pris)
  • Langue principale : Français
  • Bundle ID : sélectionne com.moobilpay.com dans la liste
  • SKU : identifiant interne unique, ex. MOOBILPAY-IOS-001
  • Accès utilisateur : "Complet"

4 Métadonnées obligatoires

  • Catégorie principale : Finance + secondaire Utilitaires
  • Description (4000 caractères max) : pitch produit
  • Mots-clés (100 caractères, séparés par virgules) : netflix, paiement, mobile money, mtn, orange, afrique
  • URL d'assistance obligatoire : page web où l'utilisateur peut te contacter
  • URL de marketing (optionnel)
  • URL de politique de confidentialité obligatoire depuis 2018 : page hébergée et publique
  • Coordonnées de contact pour Apple Review (téléphone + email valides)
  • Compte de test : email + mot de passe d'un compte démo (Apple doit pouvoir tester ton app)

5 App Privacy — déclarations légales

Tu dois déclarer toutes les données collectées :

  • Email (auth) → Contact info
  • UID Firebase → User ID
  • Token FCM → Device ID
  • Numéro de téléphone (si collecté) → Contact info
  • Données de transaction → Purchase history
Pour chaque donnée : déclare son usage (Analytics, App Functionality, etc.) et si elle est liée à l'identité.

6 Build production EAS

eas build -p ios --profile production
Vérifie ton eas.json — le profil production doit avoir distribution: "store".

7 Soumettre à Apple

Quand le build production est ✅ :

eas submit -p ios --latest

EAS uploade ton .ipa vers App Store Connect automatiquement. Ensuite :

  • Ta fiche app → TestFlight (le build apparaît après 10-30 min de traitement Apple)
  • Beta testers : possibilité de tester via TestFlight avant publication
  • App Store → sélectionne le build → Ajouter à examen → Soumettre à l'examen

8 Examen Apple (App Review)

  • Délai : 24–72h en moyenne (parfois 1 semaine si forte charge)
  • Taux de refus 1ère soumission : ~40% (normal). Apple donne la raison, tu corriges, tu re-soumets.

Pièges classiques pour MoobilPay

  • Sign in with Apple obligatoire si Google/Facebook login (Guideline 4.8)
  • Compte de test valide (sinon refus immédiat)
  • Paiement Netflix : Apple peut demander des clarifications. Bien expliquer que MoobilPay est un intermédiaire de paiement, pas un revendeur.
  • IAP Apple : si tu vends du contenu numérique consommé dans l'app, Apple exige son IAP avec 15-30 % de commission. Pour mobile money → service externe, tu es probablement exempté — à argumenter.
  • Politique de confidentialité : l'URL doit vraiment marcher et le contenu correspondre à ce que tu déclares dans App Privacy.

9 Après approbation

  • L'app passe en état Ready for sale → disponible sur l'App Store en ~2h
  • Tu choisis les pays/régions où elle est dispo (Pricing & Availability)
  • Les mises à jour passent toutes par App Review (généralement plus rapide, ~24h)

⚡ TL;DR — Ordre pratique

  1. Termine le build dev et teste à fond Apple Sign In + notifs sur iPhone
  2. Crée la fiche app sur App Store Connect (15 min)
  3. Prépare icône 1024×1024 + 3-5 screenshots iPhone (~1h)
  4. Rédige description + politique de confidentialité hébergée (~1-2h)
  5. Build production : eas build -p ios --profile production (~20 min)
  6. Submit : eas submit -p ios --latest (~5 min)
  7. Configure App Privacy + métadonnées → sélectionne le build → Submit for review
  8. Attendre 1–3 jours ⏳
